ToothFairy Japan EXE-only update publishing

한 번만: 현재 폴더의 모든 배포 파일과 .github 폴더를 함께 Commit하고 Publish/Push합니다.
GitHub 저장소 이름: leejg04133-create/ToothFairy_Japan (공개 저장소)

다음부터 사용자가 할 일:
1. GitHub Desktop에서 먼저 Fetch / Pull합니다. GitHub가 자동 만든 버전 정보 커밋을 받는 단계입니다.
2. 새 버전 폴더(예: 1.01)에 새 ToothFairyJapan.exe를 넣습니다.
3. Commit / Push합니다. latest.json을 직접 수정하거나 Prepare-Release.ps1을 실행할 필요 없습니다.
4. GitHub의 Actions에서 Publish EXE update info가 초록색 완료되면 배포 정보 갱신이 끝납니다.

GitHub가 폴더 버전과 EXE 내부 버전을 검사한 뒤 파일 크기와 SHA-256을 계산해 latest.json을 자동 커밋합니다.
1.01 폴더에 넣는 EXE는 내부 버전도 1.1.0.0으로 빌드돼 있어야 합니다. 같은 1.00 EXE를 이름만 바꿔 넣을 수는 없습니다.
같은 버전의 EXE 덮어쓰기는 업데이트 알림으로 감지할 수 없으므로 거부합니다. 항상 새 버전을 사용합니다.
변경 설명을 쓰고 싶으면 해당 버전 폴더에 notes.txt를 추가하면 됩니다. 필수는 아닙니다.
EXE만 추가하면 됩니다. 프로그램 실행에 필요한 구성 파일을 바꾼 버전은 별도로 배포 준비를 확인해야 합니다.

처음 GitHub Desktop 연결:
File > Add Local Repository > C:\Users\leejg\Documents\GitHub\ToothFairy_japan
Summary: Release 1.00 > Commit to main > Publish repository
Name: ToothFairy_Japan / Keep this code private 해제 > Publish
아직 게시 전이므로 GitHub 서버에서 자동 작업까지 실행된 것은 아닙니다.

작업 실패 시:
GitHub Actions의 실패 원인을 확인합니다. 저장소/조직 정책으로 Actions 또는 contents 쓰기가 차단돼 있으면 허용해야 합니다.
워크플로는 contents: write만 요청합니다. EXE를 실행하지 않고 파일 정보만 검사합니다.
기존 latest.json은 검증 실패 시 유지됩니다.
